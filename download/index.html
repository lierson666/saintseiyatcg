How to install

Windows

  1. Open the downloaded file SaintSeiyaTCG-1.0.0-win-x64.exe.
  2. If Windows shows “Windows protected your PC”, select More info, then Run anyway. This appears because the beta app is not yet signed with a paid certificate.
  3. Choose the install folder (or keep the default) and select Install.
  4. Open Saint Seiya TCG from the desktop shortcut or the Start menu.

macOS

  1. Open the downloaded file SaintSeiyaTCG-1.0.0-mac-universal.dmg.
  2. Drag Saint Seiya TCG into the Applications folder.
  3. Open the app from Applications. macOS warns that it cannot verify the developer, because the beta app is not notarized yet. Select Done.
  4. Open System Settings → Privacy & Security, scroll down and select Open Anyway next to Saint Seiya TCG. Confirm with your password.
  5. From now on, the app opens normally.

First launch

  1. Sign in with the email and password of your beta account.
  2. No account yet? Ask for access on the home page. We send an invitation when a spot opens.
  3. The app remembers your sign-in, so you go straight to the lobby next time.

Updates

The game updates by itself: every new card, rule or fix reaches the app as soon as it reaches the website. You only download the app again when this page announces a new app version.

Requirements

  • Windows 10/11 64-bit, or macOS 12 Monterey or later.
  • A graphics card with WebGL (any computer from the last 8 years).
  • 4 GB of RAM and a stable internet connection.

Trouble?

  • “The Sanctuary is out of reach”: check your internet connection and select Try again.
  • Blank or frozen screen: press Reload (Ctrl R).
  • Slow duels: in the duel, open Settings and lower Graphics.
  • Text too big or small: reset the zoom with Ctrl 0.

Uninstall

Windows: Settings → Apps → Installed apps → Saint Seiya TCG → Uninstall.

macOS: drag Saint Seiya TCG from Applications to the Trash.

Your decks and rank stay safe in your account.

Prefer not to install?

Play at saintseiyatcg.com/playtest in Chrome, Edge or Safari. In Chrome or Edge you can also choose Install Saint Seiya TCG in the address bar to get a window of its own, with no download.
